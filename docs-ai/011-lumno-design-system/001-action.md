- 新增 `packages/ui/src/styles/tokens.css`，集中基础尺度、页面/阅读/导航宽度、语义间距、表面、文字、圆角、阴影和 motion；`global.css` 将这些角色映射到现有 shadcn API。

- 首页采用居中的双句标题，英文使用 roman / italic，CJK 使用系统字体。七产品保持既有发布日期顺序，首项通栏，后续双列，760px 以下单列；收费模式、平台和日期估算标记保留。

- 新增 `pnpm test:visual`，并接入 release-candidate CI 和 evidence 上传；更新既有布局断言以符合新规格，保留原有功能、数据与回退检查。

## 修正过程

- 实际测量发现 gallery 图片的百分比高度未约束到媒体区域，导致设备被切断。改为相对定位媒体框与绝对填充图片，并新增真实尺寸断言；保留 `object-fit: contain`。
- 新标题原文检查发现 CJK 分隔符被添加空格；独立审核同时指出 `Rec.709` 可能被错误拆分。现保留匹配到的原始分隔符，ASCII 标点只在后接空白时切分；补充首页原文和技术术语回归检查。
- 独立审核发现导航基础选择器压过手机规则、按钮主题压过 TypeNote 播放态。拆分导航宽度覆盖，降低主题优先级，并以实际 padding、播放背景和内阴影验证修复。
- 本地 Astro dev 在已有 Moodsk 公共模块导入处报错；生产构建正常。本轮使用生产构建预览验收，没有修改不属于此次视觉任务的 Moodsk 模块导入实现。
