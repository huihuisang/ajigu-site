# 方案：借鉴 Lumno 重构全站视觉系统

状态：已定稿。实施和验收见 [001-action.md](001-action.md)。授权依据：用户明确要求「复刻借鉴这套设计和规范重构我们网站的整体风格和视觉」。

## 背景与边界

当前营销站使用共享 shadcn 组件，但首页缩在三列横向卡片中，详情页的文字层级、空间和材质尚未形成完整系统。参考调研见 [设计与 token 证据](../../memory/lumno-design-research.md)、[harness 调研](../../memory/lumno-harness-research.md)。

本方案取代 [005](../005-shadcn-redesign/000-plan.md) 与 [003](../003-gallery-home/000-plan.md) 中冲突的视觉尺寸、字阶、卡片布局和表面规范；既有业务功能、路由、文案事实及素材来源约束继续适用。采用当前工作区为基线，保留其他任务的已有改动。

覆盖首页、七个产品营销页及其现有本地化版本，共用 header、footer、卡片、FAQ、按钮和演示外框。原生 Nameplate 编辑器、旧版资源、产品演示内部界面继续保留其业务行为和产品身份；不更改下载目标、价格事实、隐私条款、SEO 元数据或上线配置。

## 设计方案

- 色彩：白色页面；暖墨标题 `#2f2a22`，正文 `#15171a`，次级文字 `#626870`；灰纸托盘 `#f3f4f6`，白色控件，细边和低透明阴影。粒子只用于装饰层，不覆盖真实产品图。
- 字体：本地打包 Open Sans、EB Garamond、Cormorant Garamond；中文、日文、韩文使用对应系统字体栈。英文 display 使用正体与斜体组合，CJK 保持独立字阶。
- 统一基础 token、语义 token 和 shadcn 映射；`tokens.css` 为拟新增的唯一设计常量入口，组件通过语义变量消费。
- 内容上限 `1360px`，阅读模块上限 `1080px`；gutter 桌面 `24px`、手机 `16px`；模块间距桌面随视口 `88–136px`、手机 `72px`；模块内距离 `24px`。
- 卡片间距 `16/12px`，文案内边距 `32/24px`，外圆角 `28/24px`，内嵌距离 `8/6px`，内圆角按外圆角减去 inset 派生。连续圆角仅作用于指定表面，胶囊保持普通 round。
- 首页：完整现有标题与说明居中；英文标题按既有两句组成 roman/italic；七个产品继续按既有发布日期排序。首项横向通栏，其余双列媒体在上卡片；小屏统一单列。保留所有平台、收费模式、发布日期、估算提示和真实 mockup。
- 详情：产品名、claim、说明与 CTA 建立清晰层次；媒体托盘、演示、说明卡片、FAQ 使用同一家族。按钮继续使用 shadcn / Radix 语义和交互。
- Header：响应式居中胶囊，品牌保留当前官方吉祥物；footer 保留吉祥物反馈。入场和 hover 使用统一 motion token，reduced motion 保持完整可读静态内容。

Image Gen 生成首页和详情工作概念，作为排版、材质和节奏参考；概念中的替代图标、虚构价格/日期及简化内容不构成产品事实，实施以当前内容数据和真实素材为准。拟保留概念于 `evidence/concept-home.png`、`evidence/concept-detail.png`，并逐项记录实际差异。

## 备选与决策

采用现有 Astro、React islands、shadcn 与 Lucide，调整 token 和公共视觉层。完全复制 Lumno 的自有 SettingsKit 会形成重复的交互实现和额外维护边界，因此继续复用本项目组件。Lum​no 品牌、油画处理图和截图不引入产品页面。

## 验收与验证

| 编号 | 验收标准 | 必要条件、验证方法与证据 |
| --- | --- | --- |
| AC-01 | 首页、详情、公共组件采用同一语义 token，字体本地托管，圆角和响应式覆盖有明确来源 | 必须；源码契约与构建检查，字体许可证归档 |
| AC-02 | 七个产品及现有元数据、排序、真实素材与目的链接保留；英文 display 和 CJK 字体分别正确 | 必须；内容测试、浏览器计算样式、首页中英文截图 |
| AC-03 | 320–1920px 页面无横向溢出，header、卡片、详情模块无裁切或重叠 | 必须；现有 browser/layout 矩阵扩充新规范断言，桌面和手机内置浏览器检查 |
| AC-04 | 语言菜单、FAQ、产品跳转、Nameplate 预览及现有产品交互保持可用；reduced motion 和无脚本回退保持可读 | 必须；现有回归套件及内置浏览器实际交互，保留结果 |
| AC-05 | 类型检查、单元测试、生产构建、构建内容检查及相关格式检查通过 | 必须；真实执行命令和输出 |
| AC-06 | 相对于参考，字体、空间、材质、媒体、控件五项有逐项对比；最终源码经独立审核 | 必须；最终截图、差异表、独立审核报告与工作区内容摘要 |

现有测试的旧布局数值按本规格更新，保留路由、数据、功能、溢出和回退检查。不得通过删除高价值断言获取通过。

## 审核与发布

依据 write-ai-doc skill，重要改动需要独立审核；在最终实现后安排独立审查 agent，仅检查本任务差异和验收证据。完成实施与本地验收后提供可打开的预览。本次没有发布线上或提交其他任务变更的授权。

无。视觉适配决策已由用户明确委托；实现中以现有内容事实与路由契约为边界。
