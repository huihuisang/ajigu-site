# 导航首屏稳定性与垂直对齐

实施：已完成。验证：78 组导航检查、40 组视觉检查、类型检查、69 项单测、生产构建与构建契约通过。审核：自检，未独立审核。

用户指出详情页语言按钮先闪过下划线内容，导航元素也未垂直居中。原因是 `SiteHeader` 在挂载前输出普通语言链接，挂载后才替换成按钮；导航链接则继承纵向布局并缺少内容居中，导致文字位置与按钮不同。

现在直接服务端渲染同一套下拉按钮，把无脚本语言链接移到 `noscript`，只在禁用 JavaScript 时显示。导航链接与语言按钮统一高度、行高和垂直内边距，并居中内容；保留键盘焦点提示和语言切换行为。

`tests/header.mjs` 阻塞外部脚本，测量初始按钮，再释放脚本并打开菜单，比较加载前后几何和文字中心线。覆盖首页、各产品和 Nameplate 的 39 个页面状态 × 手机与桌面两种宽度。TypeNote 保留原有的查询参数语言加载逻辑；该场景允许本地化文字改变按钮宽度，但保持右边缘、垂直位置和导航外框稳定。另在 320px、禁用 JavaScript 时验证 Go Sleep 的全部八个语言链接，并实际跳转到日语页面。
