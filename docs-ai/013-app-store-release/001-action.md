# 正式版下载入口更新结果

实施：已完成。验证：77 项单测、35 页生产构建、构建契约和 39 组下载入口浏览器检查通过。审核：自检，未独立审核。

Go Sleep 八种语言与 TUTU 五种语言均增加或更新首屏、独立底部下载区及页脚的 App Store 入口。Go Sleep 保留功能说明与支持入口；TUTU 删除 TestFlight 和免费测试版文案，明确免费下载、免费试编辑，保存编辑后的照片需要 Premium。FAQ 可见正文与结构化数据同步更新；两款软件结构化数据均增加正式下载地址。TUTU 的 404 与公开索引、Go Sleep 的公开索引一并更新。

Apple 官方查询于 2026-11-02 返回 Go Sleep `6799618137` 和 TUTU `6480340301` 的美区记录：版本均为 1.0，免费下载，最低 iOS 17.0，首次发布日期为 2026-10-28。TUTU 支持 iPhone 与 iPad。下载使用查询返回的原始 `trackViewUrl`，不编造商店 ID 或付费价格。新增回归先在旧内容上失败，再修正实现；已有迁移记录仅调整授权变更的动作和公开文件摘要，其他素材与支持页面校验保留。

浏览器覆盖全部 13 种页面 × 320px、1440px、无 JavaScript 三种条件。检查首屏、底部和页脚入口，确认无横向溢出、无测试版链接，并点击主要按钮验证发出的 App Store URL。外部商店导航在测试中拦截，不加载商店页面、不购买或安装应用。证据见 [evidence](evidence/)，包括 Apple 原始返回、检查日志、结果与桌面和手机截图。

地区限制：Apple 的大陆区查询返回零条记录；本环境请求商店网页时被导向大陆区 Today 页面，即使请求的是美区地址。因此已验证的是 Apple 美区发布记录与网站发出的正确链接，未验证大陆区账号可下载。没有变更 App Store Connect 的上架地区或任何线上配置。
