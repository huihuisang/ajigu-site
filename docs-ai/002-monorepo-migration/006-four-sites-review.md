规格基线为 [004-four-sites-plan.md](004-four-sites-plan.md)，视觉基线为四个原仓库上一阶段的工作室改版。审核目标为未提交工作区，运行时文件由 `evidence-four-sites/final-review.json` 的 41 个摘要标识；规格和持久证据由同目录 `version.json` 绑定。

## 独立执行的检查

- 对照四个原仓库的 22 个语言主页，正文片段、展示片段、语言入口、下载目标、canonical、hreflang、JSON-LD 和原页脚链接一致。
- 207 个迁入公共文件中 204 个与原件字节一致。Go Sleep 三个指南只修正错误 canonical 与 JSON-LD URL，正文完全一致，原 SHA 和修正记录在应用兼容清单中。
- 原产品媒体 URL 全部保留；旧 `studio/style.css`、`runtime.mjs`、`copy.mjs` 从同一份冻结参考源码生成，返回字节与原站一致，新营销页不加载这些旧脚本。
- 实际运行 17 个语言、工作区和产品测试及依赖检查，通过。六站产物契约通过，页面数与兼容文件数分别为 `9/81`、`16/136`、`5/30`、`27/52`、`30/61`、`4/41`，顺序为主站、Moodsk、TUTU、Go Sleep、DailyApod、TypeNote。
- 隔离 Chrome 抽样四站中文主页，390px、减少动态效果：正确语言和主标题、无溢出或错误、CTA 高度至少 44px。Go Sleep 事件切换、DailyApod 键盘切图、TUTU 键盘移动滑块及 Moodsk 六幕交互通过。
- 补充审核四份默认 ICO：有效包含 16/32/48px，与各站既有本地图标缩放结果一致；HTTP 200、正确 MIME、返回字节与源码一致。预览 MIME 新增一行，原审核运行时摘要保持不变。
