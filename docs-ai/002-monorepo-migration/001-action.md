## 实际实现

`apps/ajigu` 与 `apps/typenote` 使用 Astro 静态输出和 React 交互组件，直接引用 `packages/ui` 与 `packages/site-kit`。共享样式使用 Tailwind CSS，基础控件来自官方 shadcn/ui；产品内容与交互仍由对应应用管理。工作区采用 pnpm，锁文件固定实际依赖。TypeScript 使用经 Astro 检查器验证的 6.0.3。

主站保留五种语言、两份 Nameplate 介绍页及原编辑器入口。TypeNote 保留五种查询参数语言、下载链接和三个指南入口。静态编辑器及指南作为兼容资源随新构建交付。指南正文未变，修正原有错误 canonical 并声明已有产品图标。旧根目录营销 HTML 和 `studio/` 作为上一阶段视觉与兼容参考冻结，新的营销源码在 `apps/` 与 `packages/`。

TypeNote 的语言选择、声音演示、页面隐藏与缓存恢复由 React 管理。声音需主动启用；禁用存储和无脚本时仍可访问内容。共享增强脚本不修改 React 管理的节点。Nameplate 预览输入及编辑器链接可用，实际导出 PNG 为 2362 × 2362。

## 计划调整与已修问题

- Astro 7 的跨磁盘 rename 导致 EXDEV。编译中间目录改用项目共享缓存，最终产物复制到选定输出目录。交付预览放在仓库根目录 `dist`，不随任务临时目录清理；输出规则见发布记录。
- Astro 向 React 传递子节点时，Radix Slot 无法将按钮样式传给内部静态链接。增加接收简单属性并在 React 内创建链接的 `LinkButton`，两个编辑器 CTA 已在产物与浏览器中复核。
- 预览只在点击时映射域名，避免改写 SSR 属性引起 hydration 不一致；开发服务器增加静态目录入口兼容。
- 修正上游 React 插件 OXC peer 版本组合，保留各自匹配的依赖，依赖检查通过。许可证文件随两站产物提供。
- 内置浏览器服务缺少运行文件，实际使用隔离 Chrome 完成浏览器验收，未访问用户浏览器配置。
