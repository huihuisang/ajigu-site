# 详情页对齐与间距收敛

状态：用户已授权检查所有详情页并统一模块对齐与间距；沿用白色画廊。

## 观察与方案

FAQ 的 800px 居中覆盖已经删除。本轮进一步发现演示、正文与折叠区分别使用 56/64/48px 外边距，移动端为 40/44/48px；模块节奏依赖 margin collapse 和 Astro 岛的 display:contents。TypeNote 的简谱与下载多层包装绕过正文标题间距，DailyApod 的 gallery 包装也存在不同的标题间距入口。

统一使用 1040px 内容宽度与既有响应式侧边距。详情正文由一个页面 flow 管理模块间距：桌面 64px、640px 及以下 48px；模块内部标准标题/内容间距 24px。首页、导航宽度、居中首屏与产品演示内部构图维持现有设计。折叠内容继承外层宽度，不再重复收窄。

首选集中布局与共享令牌，避免逐页补 margin；不新增 UI 控件，不修改原 URL、内容和专属演示逻辑。TypeNote 简谱/下载去掉无样式的旧包装，保留锚点、文案与操作。没有未经确认的新设计方向。

## 验收与验证

- AC-L1：六个产品全部本地化详情页，320/390/640/768/1024/1440px 下模块、标题、页脚内容的左右边界一致，无水平溢出。
- AC-L2：相邻模块的实际距离符合统一的 64/48px 令牌；共享标题与直接内容距离 24px；首屏内部与演示内部布局不套用此规则。
- AC-L3：逐个展开补充章节，内文边界不重复缩进；FAQ 键盘展开与无脚本正文均可用。
- AC-L4：必要格式、类型、构建、兼容契约和现有交互回归通过；新增布局检查先失败后通过，接入现有验证入口。

独立源码复审是必要条件；浏览器实际布局验收由主代理完成。结果拟记录在 007-detail-layout-action.md 和 evidence-detail-layout。未授权提交或发布，临时输出保留。
