## 审查与拟改动

| 观察 | 位置 | 修正 |
| --- | --- | --- |
| 11–12px 小字、小标题负字距影响阅读 | gallery.css | 说明 13px、元信息 12px，取消小字负字距；允许卡片按内容增长 |
| 14/18px 大块间距脱离共享节奏 | 首页与移动端布局 | 大块间距回到 4px 网格，保留控件内部微调 |
| 模板画布 #efefef 与 muted 不同，出现色带 | 首页、详情主图 | 语义媒体底色匹配既有图片，不改截图或设备角度 |
| 通用演示标题重复 | TypeNote、Nameplate、四站模板 | 本地化为具体操作说明，保留内容、顺序与功能 |
| 三个同等按钮争夺注意力 | Moodsk hero | 第三个入口使用原 shadcn link 变体，保留地址 |
| Sparkles 与品牌无关 | 页脚彩蛋 | 改用原有 ajigu 小鸭，继续主动触发并尊重 reduced motion |
| 文本箭头与 Lucide 混用 | LinkButton、NamePreview | 复用 Lucide，装饰图标不重复朗读 |
| transition-all 范围过大 | 已使用的 Button、Accordion、NavigationMenu | 显式列出过渡属性，保留官方结构与语义 |
| 多个正文标题随滚动入场 | enhance.ts | 只给显式标记的介绍一次轻入场；保留产品解释动画 |

按间距、颜色、图标、文案、字体、布局、细节、图片、动效九遍处理。精修只修改上述问题；保留真实品牌字标、原字体、居中详情布局、应用图标及原生展示素材。不按泛化装饰规则删除 Moodsk 业务动画，不引入新依赖或技能脚本为网站运行时。
