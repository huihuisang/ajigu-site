# 方案：正面设备模板与静态成品图

状态：已实施，本地验收与独立审核通过。结果见 [001-action.md](001-action.md)，审核见 [002-review.md](002-review.md)。

用户否定上一版多角度和图标物体，要求寻找免费 iPhone、iPad、Mac mockup 模板，将真实截图放入模板，首页直接显示合成图。本轮保留六格、三／二／一列、标题及统一应用图标，替换媒体制作与展示方式。

采用 MockUPhone 正面设备模板，保留来源、贡献者信息与许可。官网声明生成作品采用 CC BY 3.0，源仓库为 Apache-2.0；分别记录，不混为同一种许可。将截图离线合成到模板屏幕区，输出一张完整 WebP；浏览器不再排列设备图层或施加透视、旋转、漂浮动画。图内不新增营销文案。

真实截图优先复用前轮已确认来源；TypeNote 改用经过当前原生视图代码核对的实际窗口截图，DailyApod 优先取得当前原生构建实拍。保留截图比例，不拉伸，不生成虚构 UI，不以图标代替产品界面。原生工程保持只读，未发布站点。

| 编号 | 验收条件 | 验证 |
| --- | --- | --- |
| AC-01 | 六格均直接显示一张完整 mockup 图，无页面旋转及透视 | 源码、构建 HTML、实际浏览器计算样式 |
| AC-02 | 使用免费正面 iPhone、iPad、Mac 模板，保存来源和许可 | 官方来源、模板及输出摘要、屏幕合成检查 |
| AC-03 | 实际产品界面完整、无拉伸、无空屏，不用放大图标代替 | 原始截图核对、成品逐图检查及独立审核 |
| AC-04 | 图标规格、链接、语言、响应式保持 | 类型、必要单测、三尺寸与主路径浏览器回归 |
| AC-05 | 最终源码、证据与许可对应 | task-artifacts 真实校验及源码绑定 |

沿用 write-ai-doc 与 task-artifacts 流程；独立审核是交付条件。按用户指定的现成模板做确定性截图合成，不调用生图工具重绘界面。模板与截图为可维护制作输入，成品为站点资源；临时下载与渲染放入本任务目录。
