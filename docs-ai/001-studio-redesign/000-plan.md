# 方案：工作室展厅与产品页统一设计

状态：已确认；本地实施已完成，验证与审核见 001-action.md

## 背景与授权

2026-10-31，用户确认重构主站和六个产品的营销入口，并选定第一张效果图的包豪斯结构，加入第二张的局部波普元素。视觉稿仅作为构图参考，生成的产品界面不能作为真实产品素材。

主站已有五语言主页和 Nameplate 编辑器。五个产品子站分别维护静态页面，Moodsk 已有六幕交互演示。保留各站仓库、域名、语言集合、下载目标、指南和法律正文。主站及 DailyApod 的既有未提交改动属于用户工作，不覆盖或回滚。

## 目标与非目标

- 首页先介绍“认真做有趣的小工具”的理念，再以真实素材展示六件作品。
- 共享导航、字体、间距、按钮、产品页结构与动效基础；每件产品通过三原色主次、展品和功能演示表达个性。
- 新增 Nameplate 营销页，保留原编辑器及其语言路径。
- 不迁移框架，不修改原生应用、购买流程、价格、既有编辑器行为，不在本轮自动上线。

## 方案与取舍

使用红 `#D92D27`、蓝 `#2347D9`、黄 `#FFD23F`、近白与黑；大字与几何展台构成主结构，网点和少量拼贴只用于展品周围。尊重用户已选视觉，不采用技能随机蓝图覆盖已确认构图。系统字体保证中日韩文字覆盖，不请求第三方字体。

拟新增主站 `studio/`，保存共享样式、脚本、静态模板与每站内容契约。各站持有独立的本地副本，通过显式同步及摘要校验避免漂移。静态 HTML 包含完整正文和导航；脚本只增强演示及动效。原有翻译正文与指南引用作为迁移输入保留，生成结果可重复构建。

产品演示分别为 TypeNote 指定输入区和琴键、Go Sleep 示例时间轴、DailyApod 视图切换、Moodsk 原有六幕演示、TUTU 真实操作对比、Nameplate 姓名预览。所有交互支持触摸、键盘及减少动态效果；不请求麦克风、不上传文件、不自动播放声音，不伪装浏览器正在执行原生 AI。

Nameplate 新入口为 `/nameplate/about/` 与 `/nameplate/about/zh-hans/`。原 `/nameplate/` 与 `/nameplate/zh-hans/` 保持不变。

## 审核与发布

最终改动需要独立审核，重点为跨站同步、翻译完整性、演示可访问性和未授权范围保护。各仓库独立登记临时产物，持久证据写入本主题记录。仅交付本地可审阅版本；提交、推送及上线另行依照用户授权处理。无已验证远端提交时保留临时产物。

## 待确定事项

无剩余产品方向决策。素材或运行环境缺口以实际检查结果记录，不用生成界面冒充真实产品证据。
