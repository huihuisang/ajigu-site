## 实际改动

- 新增产品技能要求详情页有独立、可见的核心功能展示区。先确定主要任务、关键操作和可见结果，再选真实截图或实际操作视频；只有介绍内容的首页、图标、空状态和纯文字不能代替演示。首页本身就是核心工作区时，只要展示真实操作与结果，仍然符合要求。
- LogLift 的 `showcase` 使用 24.5 秒实际成片，展示导入、滑杆对比、同步预览和导出；保留原生控制、静音、封面和媒体入口，不自动播放。五语言均有导入、对比、导出静态摘要，说明视频界面与字幕为简体中文。
- 用户在明确知悉网站与公开仓库的范围后，回复“允许公开这支成片”。原始本地交付保持不变，公开副本与原片的 SHA-256 一致；来源与授权见 `design/mockups/videos.json`。
- 实测发现本地预览可以播放视频但无法跳转进度，补充静态资源 HTTP 字节范围响应。GET 支持单段、开放尾部和后缀范围；无效或不可满足的字节范围返回 416。HEAD 与未知单位忽略 Range，符合 [RFC 9110 §14.2](https://www.rfc-editor.org/rfc/rfc9110.html#section-14.2)。该修复只作用于本地预览服务。
