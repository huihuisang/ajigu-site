# 实施结果：作品网格与共享应用图标

实施：已完成。验证：通过本地构建、类型检查、46 项测试与 228 项浏览器页面／视口检查。独立审核：通过，见 [002-review.md](002-review.md)。规格基线：[000-plan.md](000-plan.md)。

## 实际改动

主站五语言首页改为六格作品展示，移除原大首屏、理念区与画布内营销文案。每格保留一张真实图、当前图标物体或三张手机 mockup，支持不同角度与裁切；桌面三列、平板两列、手机一列。名称、应用图标和平台信息置于画布外。

新增共享 `AppIcon`，首页名称旁为 36px，产品营销导航为 48px；圆角均为边长的 22%，两层柔和阴影及内描边完全相同。原生 macOS 图标去除平台外侧留白后再导出，保持图案来源。所有输出均为 WebP，原始图标和历史资源不覆盖。

素材清单为 `packages/site-kit/icons/sources.json`，记录原始来源、SHA-256、尺寸与版本依据。清单不进入站点公开产物。TypeNote 使用本轮 Apple `actool` 编译当前 `.icon` 的完整图标；Moodsk 使用当前 1.2(541) 图标与实际截图；Go Sleep 使用恢复命名后的实际界面；TUTU 使用底部工具布局的已验收截图；DailyApod 使用当前默认图标；Nameplate 使用本轮实际 3D 编辑器截图。TypeNote 的未定版本菜单图和 DailyApod 的未加载完整界面均未用于新首页。
