# 浏览器语言自动匹配

状态：方案已采用。改动前，静态站点根路径默认英文。用户希望按系统语言自动匹配，网页以浏览器提供的语言偏好列表为依据。

采用现有语言目录，在语言中性的英文入口按“URL 语言参数、手动选择、浏览器偏好、英文”匹配。带语言路径的链接保持原语言。支持中文简繁体与英语地区变体；不支持的偏好继续检查下一项，最终使用现有英文默认项。手动选择保存在当前站点的本地存储；显式英文链接携带语言参数，避免存储不可用时被再次自动切换。

静态页面在头部、正文之前执行轻量跳转，使用现有相对地址并保留查询参数与锚点；不增加服务端运行时或修改 canonical、hreflang、站点地图。TypeNote 继续使用现有查询参数与客户端语言状态，加入浏览器偏好并兼容历史保存键。Nameplate 编辑器与复制的旧静态支持页面不在本轮改造范围；主站、共享产品落地页及 Nameplate 介绍页纳入。

验收：AC-01，中文简繁、日语、韩语、英文地区及未知语言正确匹配；AC-02，显式语言与手动选择优先，英文可强制选择；AC-03，已有语言路径不被覆盖，查询参数及锚点保留，无跨站跳转或循环；AC-04，存储被拒绝与禁用 JavaScript 时仍能阅读页面和切换语言；AC-05，TypeNote 查询参数与旧偏好保持兼容。通过纯函数与真实浏览器测试验证，并运行类型、单测、生产构建和构建契约。此项沿用现有路由及组件，进行自检，不要求独立审核。
