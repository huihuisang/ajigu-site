# 浏览器语言匹配实施结果

实施：已完成。验证：全部验收及全站浏览器回归通过。审核：自检，未独立审核。

首页、共享产品落地页及 Nameplate 介绍页已接入正文之前运行的语言匹配脚本。明确语言路径保持原语言；默认英文入口优先读取有效的语言参数，其次使用手动保存的选择，再按浏览器偏好列表匹配，最终保留英文。匹配区分中文脚本和地区、英语地区变体；同语言变体不存在时选择产品已有版本。手动切换使用站点存储，自动检测不写入偏好。英文菜单链接显式携带语言参数，因此存储被拒绝时仍可选择英文。

TypeNote 沿用原查询参数与客户端语言状态，使用同一匹配函数，并兼容旧的 `tn-lang`。未改造 Nameplate 编辑器或复制的旧静态页面；这些页面继续遵循原有地址语言。canonical、hreflang 与站点地图保持原内容。

- AC-01：通过。简体、繁体、香港地区、日语、韩语、英国英语、法语与次选偏好均有专项浏览器覆盖；各产品只使用已有语言版本。
- AC-02：通过。显式地址和参数优先，手动选择可跨产品保留，拒绝存储时仍能通过显式英文链接返回英文。
- AC-03：通过。已有语言路径不被覆盖，查询参数和锚点保留，预览始终留在当前来源。构建产物确认脚本位于正文之前。
- AC-04：通过。存储被拒绝时按浏览器偏好匹配；禁用 JavaScript 时显示英文静态首页，原有语言链接可导航至日语页面。
- AC-05：通过。TypeNote 的显式参数、站点偏好、旧存储键和浏览器偏好均已验证。

已执行类型检查、74 项单测、35 页生产构建、构建契约、27 组语言场景、78 组导航检查与 248 组全站页面及视口回归，均通过。专项测试先在旧英文默认构建上失败，再验证新构建。内嵌浏览器访问根地址后实际进入简体中文，截图保存在 [evidence](evidence/)。旧的浏览器回归已按新规则更新：英文菜单带明确语言参数，返回首页保留手动语言，独立的英文产品交互测试显式指定英文。
