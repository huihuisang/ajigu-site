Mac キーボードに打鍵音を付ける方法

タイピングは、あなたが一日中すでに作っているリズムです。音程を与えると、地味な入力が不思議に満たされる——しかもセットアップは2分。

打鍵音が効く理由

メカニカルキーボードのカチッという音が気持ちいいのは、1回1回の入力を確認してくれるから。音程のある音はさらに先まで行きます。書き手は集中に、開発者はフローに。机がピアノになるのを楽しむ人も。

一番簡単な方法：TypeNote

  1. TypeNote（無料・オープンソース）をダウンロードして Applications へ。
  2. 開くと macOS のメニューバーに常駐します。
  3. 128の General MIDI 音色から選択。ピアノ、プラック、波の音など。
  4. あとはタイピングするだけ。どのアプリでも、8ms 未満のレイテンシで1キー1音鳴ります。

単音だけじゃない

TypeNote はメロディも読み込めます。数譜（1–7）、MusicXML、MIDI で曲を書くと、キーボードがその順番に演奏。スマートミュートで通話やメディア再生中は自動で静かになります。
