# Lumno 参考视觉重构

- 用户于 2026-11-02 明确要求借鉴 Lumno 重构全站风格。当前设计入口为 `docs-ai/011-lumno-design-system/000-plan.md`；替代旧 Gallery White 的布局尺寸、字阶、圆角和表面规范。保留业务、素材和路由约束。
- `packages/ui/src/styles/tokens.css` 是统一设计常量入口；`global.css` 提供 shadcn 映射，`site.css` 负责共享营销样式，`gallery.css` 负责作品区组合。组件主题规则使用低优先级，不能覆盖产品交互状态。
- 本地字体为 Open Sans Variable、EB Garamond 600、Cormorant Garamond Italic 600；CJK 使用对应系统字体。保留字体 OFL 并随构建发布。
- 首页保持七产品的发布日期排序、平台、收费模式、日期估算标记和真实 mockup。首项宽卡，其他双列，760px 及以下单列。原图必须完整显示，媒体使用明确边界及 object-fit，不得裁断设备。
- `DisplayTitle` 保留原文空白；Latin 句界必须有空白，不能拆开 `Rec.709` 等术语。CJK 不额外插入空格。
- 审核结果和实际验收证据记录在本主题的 `001-action.md`；后续修改须重新验证，不能沿用旧版本结果。
- 用户于 2026-11-02 修正卡片信息层级：64px 图标左置，右侧名称下放平台与收费信息；描述位于整个标题行下方，左边缘与图标对齐；发布日期独立置底。标题与平台/收费间距 8px，标题行与描述间距 16px。所有七张卡片一致，窄屏允许元信息自然换行。
- 导航语言按钮必须直接服务端渲染，不使用挂载状态把普通语言链接替换为下拉按钮；无脚本语言链接仅放在 `noscript`。导航链接与语言按钮统一 40px 高度、零垂直内边距、1.5 行高并居中内容。`tests/header.mjs` 延迟脚本后比较首屏与加载后几何，覆盖所有共享导航页面及无脚本切换。
