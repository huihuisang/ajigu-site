- Classic uses the lower half of the legacy square artwork. New backgrounds are complete 2:1 panels and must not use Classic's source crop. Template text coordinates use a 2362 by 1181 reference panel and scale with the current card size.
- Load the background images before building thumbnails or applying the initial template. Resolve their URLs against the shared app script directory, not the active locale path.
- Locale switches rebuild localized thumbnails and translate only the built-in sample name. User-entered names and the selected template remain unchanged.
- Default text fonts follow the editor locale: English uses `system-ui, sans-serif`; Chinese uses the Heiti fallback stack. Name, Number, and new text layers use this default unless the template specifies a font. `usesDefaultFont` tracks automatic selection; font-picker choices and uploaded fonts clear it. Locale switches update automatic fonts only. Built-in font labels are localized, while uploaded and system font names remain unchanged.

Browser checks confirmed automatic English-to-Chinese changes, manual Heiti preservation when returning to English, new-layer defaults, PNG export success, and no mobile horizontal overflow. Uploaded font files and downloaded PNG contents were not inspected.

At a measured 375px mobile width, document width equaled scroll width and all five options remained present. The regression suite now has 12 passing tests.
